About Event
​Aesthetics can now be generated cheaply. That makes taste all the more worthwhile to build thoughtfully. Non-slop is a one day hackathon where you use AI to build something intentional that makes people feel something.

​Theme: What matters when you can generate anything? Can you explain your choices?

​The Challenge
​Build something with AI that has value beyond a simple prompt. It can be a video, an image, a 3D printed object, a game, or anything else.

​Build with Pangram’s API (AI detection), Kino (AI video editor), Capy (AI software engineer), and Paper (AI design workflow), plus any other tools you like.
