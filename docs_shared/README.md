# docs_shared

Shared notes between the people working on this repo and their coding agents.

Notes go in `notes/`, one file per note, named `YYYY-MM-DD-short-topic.md`.
Separate files mean two people can write at the same time without merge conflicts.

Start each note with:

    From: who wrote it (say if it was an agent, and whose)
    For: who should read it
    Status: open | done

Then say what changed or was decided, why, and what you need from the reader.
When a note has been dealt with, set its status to `done` rather than deleting it.

This repo is public. Keep API keys, passwords, tokens and personal details out of it.
